### 🔐 [SecureCloud](https://github.com/Yash07-pixel/securecloud)
*Production-Grade Encrypted File Storage* | Full-Stack Application
> Military-grade security meets user-friendly design. End-to-end AES-256-CBC encryption with per-user keys, JWT authentication, and zero-knowledge architecture.
- *AES-256-CBC encryption* — client-side before transmission
- *Per-user encryption keys* — users own their data completely
- *JWT-based authentication* — stateless, scalable auth
- *Live on Vercel + Render* — production-ready infrastructure
- Upcoming: Email OTP verification with Resend API (custom domain pending)

`AES-256` `FastAPI` `React/Vite` `MongoDB Atlas` `JWT` `Security-First`

### 🧬 [MolGenix](https://github.com/Yash07-pixel/molgenix)
*AI-Powered Drug Discovery Platform* | Full-Stack Application
> From plain English to ranked drug candidates. Autonomous 5-stage pipeline combining Gemini AI, cheminformatics, and molecular docking to accelerate early-stage drug discovery.
- *Natural language target input* — describe a disease target in plain English
- *AI-driven molecule generation* — RDKit variants + ChEMBL bioactive compounds
- *ADMET prediction* — toxicity, bioavailability, BBB penetration via DeepChem
- *Molecular docking* — AutoDock Vina binding affinity scoring with fallback heuristics
- *Auto-generated research report* — full PDF with Gemini-written molecule rationales

`FastAPI` `React/Vite` `PostgreSQL` `RDKit` `DeepChem` `Gemini-AI` `Docker`
