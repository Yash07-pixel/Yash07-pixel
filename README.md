## 🔨 Featured Projects

### 🧬 [MolGenix — AI-Powered Drug Discovery Pipeline](https://github.com/Yash07-pixel/molgenix)
**AI · Cheminformatics · Full-Stack** | Hackathon Runner-up @ Augmentix, NMIT
> From plain-English disease descriptions to ranked drug candidates — compressing early-stage screening from months to minutes.
- **End-to-end pipeline** — converts natural language input into novel molecules with docking scores and 3D visualizations
- **DeepChem GNN models** — predicts hepatotoxicity, hERG cardiotoxicity, BBB penetration, and bioavailability via a traffic-light scoring system
- **AutoDock Vina docking** — docks against real RCSB PDB structures; RDKit R-group substitution for lead optimization
- **One-click PDF reports** — investor- and grant-ready research reports via ReportLab

`React` `FastAPI` `RDKit` `DeepChem` `AutoDock Vina` `Gemini API` `PostgreSQL` `Docker`

### 🔐 [SecureCloud — Encrypted File Storage](https://securecloud-app.vercel.app)
**Production-Grade Security · Full-Stack** | [Live](https://securecloud-app.vercel.app) · [GitHub](https://github.com/Yash07-pixel/securecloud)
> Military-grade security meets user-friendly design. End-to-end AES-256-CBC encryption with per-user keys, JWT authentication, and zero-knowledge architecture.
- **AES-256-CBC encryption** with SHA-256 integrity verification — client-side before transmission
- **Per-user encryption keys** — zero cross-user data exposure
- **JWT + bcrypt auth** — expirable share links, SlowAPI rate limiting, trash & file recovery
- **Deployed on Render + Vercel + MongoDB Atlas** — production-ready infrastructure

`AES-256` `FastAPI` `React/Vite` `MongoDB Atlas` `JWT` `Security-First`

**[Try it live →](https://securecloud-app.vercel.app)** | **[Source code →](https://github.com/Yash07-pixel/securecloud)**
